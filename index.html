🛠️ How to Use r2modman

Getting Started With Your First Game

  1. Launch r2modman – You'll see a game selector screen.
  2. Choose a game – Select from Valheim, Risk of Rain 2, Lethal Company, or any supported title in the list.
  3. Create a profile – Give your mod setup a name (e.g., "My First Mods").
  4. Browse mods – The integrated Thunderstore browser shows thousands of community-created mods.
  5. Install mods – Click "Install" on any mod, and r2modman handles everything automatically.
  6. Launch the game – Press the play button, and r2modman starts your game with all mods loaded.
💡 Pro Tip: If your game isn't launching or mods aren't working, check that all dependencies are installed. r2modman marks required dependencies automatically so you know what to add.

❓ Frequently Asked Questions

Is r2modman really free?

Yes, 100%! r2modman is completely free to download and use. There's no premium tier, no paywall, and no hidden costs.

Will it work on my computer?

If your computer can run the games you want to mod, it can run r2modman. The application is lightweight and uses minimal system resources. No special hardware required.

What if I break something?

No worries! r2modman creates a safe environment for each game profile. You can revert changes instantly and even wipe everything clean without affecting your actual game files.

Can I play online with mods?

Most games allow modded play, but it depends on the game's rules and the specific mod. r2modman makes it easy to switch between modded and vanilla profiles so you can play however you prefer.

🔧 Troubleshooting Common Issues

Mods not working?

  • Make sure you've installed the mod's required dependencies
  • Always check the mod's compatibility with your current game version
  • Try creating a fresh profile and adding mods one at a time

Game won't launch?

  • Continue to launch the game through the r2modman play button
  • Verify the game's integrity via Steam or your game client
  • Update all mods to their latest versions
